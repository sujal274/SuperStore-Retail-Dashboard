# 📊 Excel Sales & Profit Dashboard

An interactive **Sales & Profit Analysis Dashboard** built in Microsoft Excel using **Power Query, Power Pivot, DAX, Pivot Tables, Pivot Charts, Charts, Slicers, and Filters**.

The project transforms raw business data into an interactive dashboard that helps analyze sales, profit, and profit margins across different product categories.

---

## 📌 Project Overview

This project demonstrates an end-to-end **Excel Data Analytics and Business Intelligence workflow**.

Raw business data was first cleaned and transformed using **Power Query**. The cleaned data was then organized into a relational **Power Pivot Data Model**. DAX measures were created to calculate important KPIs such as Total Sales, Total Profit, and Profit Margin.

Finally, **Pivot Charts, Charts, Slicers, and Filters** were used to create an interactive dashboard for business analysis.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Clean and transform raw business data using **Power Query**.
- Build a structured data model using **Power Pivot**.
- Create business KPIs using **DAX measures**.
- Analyze sales and profit across different categories.
- Compare sales performance with profitability.
- Create interactive visualizations using Pivot Charts and Charts.
- Add Slicers and Filters for dynamic data exploration.
- Identify high-performing and low-performing categories.
- Generate useful business insights from the data.

---

## ❓ Business Questions

The dashboard is designed to answer the following questions:

1. What are the total sales generated by the business?
2. What is the total profit generated?
3. What is the overall profit margin?
4. Which category generates the highest sales?
5. Which category generates the highest profit?
6. Which category has the highest profit margin?
7. Which category has a low profit margin despite generating high sales?
8. How do sales and profit vary across categories?
9. Which categories contribute the most to overall profitability?
10. Where are there potential areas for improving profitability?
